# 918-nji madda. Ätiýaçlandyryş şertnamasynda başga şahsyň hukuklary
1. Başga şahsyň peýdasyna ätiýaçlandyryşda şu şertnamadan gelip çykýan hukuklar şol şahsa degişlidir. Diňe ätiýaçlandyrýan ätiýaçlandyryş şahadatnamasyny talap etmek hukugyna eýedir.
2. Ätiýaçlandyrylan şahs ätiýaçlandyrýan bilen ylalaşmazdan öz hukuklaryndan peýdalanyp biler we diňe, eger ätiýaçlandyryş şahadatnamasy onuň elinde bolsa, öz hukuklarynyň kazyýetiň üsti bilen amala aşyrylmagyny talap edip biler.
