# 998-nji madda. Gaýtadan bermek
Eger görkezijä berlen bergi borçnamasy zaýalanmagy netijesinde mundan beýläk dolanyşyga ýaramsyz bolsa, onda bergi borçnamasynyň esasy manysyny we tapawutlandyryjy alamatlaryny anyk belli etmek mümkinçiligi bolsa, ony saklaýjy özüne resminamany beren şahsdan zaýa bolan resminamany yzyna gaýtarmak şerti bilen, özüne täze bergi borçnamasynyň berilmegini talap edip biler. Saklaýjy ähli çykdajylary çekýär we olary öňünden tölemelidir.
