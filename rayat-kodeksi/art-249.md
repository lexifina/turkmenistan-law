# 249-nji madda. Maslahat beriji geňeş
1. Ýaşaýyş jaý eýeleri sesleriň ýönekeý köplügi bilen maslahat beriji geňeşi döretmek hakynda çözgüt kabul edip bilerler. Maslahat beriji geňeş başlykdan we iki agzadan ybaratdyr.
2. Maslahat beriji geňeş başlygyň öz wezipelerini amala aşyrmagyna ýardam berýär.
3. Maslahat beriji geňeş maliýe we hojalyk meýilnamalaryny, hojalyk meýilnamasynyň ýerine ýetirilişiniň jemlerini, hasabatlary, çykdajylaryň sanawyny ýaşaýyş jaý eýeleriniň ýygnagynda garalmazyndan öň barlamalydyr we degişli netijä gelmelidir.
4. Maslahat beriji geňeş başlyk tarapyndan zerurlygyna görä çagyrylýar.
