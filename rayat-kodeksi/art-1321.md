# 1321-nji madda. Zat (emläk) hukuklaryna ulanylýan hukugyň hereketiniň çygry
1. Zat (emläk) hukuklaryna ulanylýan hukuk bilen şu aşakdakylar kesgitlenilýär:
1) zat (emläk) hukuk obýektleriniň görnüşleri, şol sanda emlägiň gozgalmaýan ýa-da gozgalýan zatlara degişliligi;
2) zat (emläk) hukuklarynyň obýektleriniň dolanyşyk ukyplylygy;
3) zat (emläk) hukuklarynyň görnüşleri;
4) zat (emläk) hukuklarynyň mazmuny;
5) zat (emläk) hukuklarynyň ýüze çykmagy we ýatyrylmagy, şol sanda eýeçilik hukugynyň geçmegi;
6) zat (emläk) hukuklarynyň amala aşyrylmagy;
7) zat (emläk) hukuklarynyň goragy.
2. Eger Türkmenistanyň kanunçylygynda başgaça göz öňünde tutulmadyk bolsa, geleşik boýunça ýoldaky (tranzitde) gozgalýan emläge eýeçilik hukugynyň we beýleki emläk hukuklarynyň ýüze çykmagy we ýatyrylmagy bu emlägiň iberilen ýurdunyň hukugy bilen kesgitlenilýär.
3. Taraplar, üçünji taraplaryň hukuklaryna zyýan ýetirmezden, gozgalýan emläk babatda eýeçilik hukugynyň we gaýry zat (emläk) hukuklarynyň ýüze çykmagyna, ýatyrylmagyna ulanarlykly bolan hukuk barada özleriniň geleşiginde ylalaşyp bilerler.
4. Hukuk ediniş wagt möhleti sebäpli zada (emläge) eýeçilik hukugynyň we zada (emläge) bolan gaýry emläk hukuklarynyň ýüze çykmagy hukuk edinişiň wagt möhletiniň tamamlanan pursadynda zadyň (emlägiň) ýerleşen ýurdunyň hukugy bilen kesgitlenilýär.
